# Experiment figures

Generated by `make_figures.py` from `KATCaptures/` (gitignored raw data) and `HuskyBags_from_robot_20261120/`. Each figure is saved as PNG (200 dpi) and PDF. Per-session numbers are in `session_summary.csv`.

- KAT sessions parsed: 203; with > 20 s connected KAT data: 60; DirectAngle real-car drive sessions: 50 (12 with GYRO HEADING STALE, excluded from tracking/response figures as failed runs).
